# DOCUMENT NUMBER TERMINOLOGY
This defines the official professional terminology for Smart Freight NTT document generation.

## 1. CANONICAL PREFIXES
- `QT` = Quotation
- `BK` = Booking
- `JOB` = Job / Shipment
- `HBL` = House Bill of Lading
- `MBL` = Master Bill of Lading
- `INV` = Invoice
- `RCT` = Receipt
- `PAY` = Payment Reference
- `CN` = Credit Note
- `DN` = Debit Note

## 2. PROFESSIONAL TRANSLATION STANDARD (Thai / English)
- **Quotation No.** (เลขที่ใบเสนอราคา)
- **Booking No.** (เลขที่ Booking) - *Do not translate to Thai literally.*
- **Job No.** (เลขที่ Job) - *Do not translate to Thai literally.*
- **House B/L No.** (เลขที่ House B/L)
- **Master B/L No.** (เลขที่ Master B/L)
- **Invoice No.** (เลขที่ใบแจ้งหนี้)
- **Receipt No.** (เลขที่ใบเสร็จรับเงิน)
- **Credit Note No.** (เลขที่ใบลดหนี้)
- **Debit Note No.** (เลขที่ใบเพิ่มหนี้)
- **Payment Reference** (เลขที่อ้างอิงการรับชำระ)

## 3. UI PLACEHOLDER STANDARD
Placeholders should always demonstrate the format realistically.
- `e.g. QT-2608-0048`
- `e.g. BK-2608-0124`
- `e.g. JOB-2608-0137`
- `e.g. INV-2608-0001`
